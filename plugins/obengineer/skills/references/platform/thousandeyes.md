# ThousandEyes

Load only when evidence contains an off-box DNS, CDN, internet, workforce, partner, or SaaS
path that application telemetry cannot observe.

Choose HTTP/page-load/transaction, DNS, BGP, cloud/enterprise agent, or endpoint tests from
that path. Align test labels with bounded `page.type` and `<org>.bt`; tests are not a source
of workflow spans.

When APM already identifies the slow handler, ThousandEyes is supporting evidence rather
than the root span. Unknown account-group access becomes an unresolved ledger item.
