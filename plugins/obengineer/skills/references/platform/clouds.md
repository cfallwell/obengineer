# Cloud and runtime placement

Load only for deploy targets or production inventory in evidence.

Supported evidence may identify AWS, Azure, GCP, Kubernetes/OpenShift, VMs, on-premises,
or edge runtimes. The contract names only observed services and specifies Collector
placement, OTLP paths, OTTL/redaction, spanmetrics, Metrics Pipeline Management, and the
MetricSet split for those services.

Do not load a provider playbook because a repository contains an SDK package. Unknown cloud
or runtime becomes an unresolved provenance-ledger item.
